## 记分规则

| 判定 | 含义 |
|------|------|
| ✅ 正确 | 论点成立，方向与时点都对 |
| ⚠️ 部分 | 方向对但时点错，或只兑现一半 |
| ❌ 错误 | 被事实证伪 |
| ⏳ 待验 | 尚未到检验窗口 |

**登记要求**：每条论点必须写明**可证伪的检验条件**，否则不予登记。

**三条门槛要求**（前两条来自 SOL 首期教训，第三条来自本期推理审查）：

1. **门槛必须够得着。** 设一个现实触发不了的门槛等于自我豁免，会虚高正确率。
2. **论点必须是预测，不是定义。** 一个框架选择（如"ADA 是期权型资产"）无法被世界证伪，不予登记。
3. **证伪区间必须与论点区间同构。** 若论点说"落在 A 区间"，证伪条件就不能是"落在比 A 宽 30% 的 B 区间之外"——那等于换了一个更容易对的论点。

## 本期方法论的已知弱点（首期即声明）

1. **估值框架完全建立在参照资产的选择上。** 乐观情景用 SOL 当前市值作锚，而 SOL 自身距 ATH –65.5%、网络收入同比 –87%。**用一个自身估值存疑的资产作参照，误差被完整继承。**
2. **概率（12/46/42）是主观赋值，不是计算结果。** 且报告 9.7 已证明：**本报告的参数组合在数学上无法与当前市价自洽**（固定乐观 12% 反解悲观地板得负值），即这套参数本身就预先隐含了"ADA 被低估"的结论。**报告因此拒绝给出方向性判断。**
3. **悲观地板的倍数（ALGO 的 1.5–3.5 倍）没有严格推导。** 这个 42% 权重情景的地板设定，与乐观概率是同一级别的杠杆。
4. **情景集不完备。** 缺失"价格上涨但链上使用继续恶化"这一现实可能——2026 年 8 月本身就是这种模式的小样本，而本框架无法生成它。
5. **治理事件的部分叙述仍依赖 CryptoSlate 一家媒体**（宪法委员会投票、ETF 撤回、基金会年报）。三处均已打开原文，但单一媒体的选题倾向无法通过"打开原文"消除。
6. **未能取得 Cardano 生态内部对治理争议的完整陈述**（反对方 DRep 的公开理由汇总）。
7. **开发者活动数据完全缺失。** developerreport.com 抓取失败，本报告因此未使用任何开发者数量指标。对一个"技术路线能否兑现"是核心问题的资产，**这是一个实质性的证据缺口**。
8. **IOG 除国库外的资金来源未考察**（自有营收、早期 ADA 分配、Midnight 相关融资）。本期虽已确认国库拨款到位，但 IOG 的整体财务状况仍是零证据区。

## 本期最重要的过程记录：一个被外部审查抓出的致命错误

**初稿的核心论断是错的**，而且错得很彻底：

| | 初稿（依据多家媒体一致报道） | **链上一手记录** |
|---|---|---|
| IOG「Cardano Vision 2026」3,291.6 万 ADA | "DRep 86.72% 反对，提案被否决" | ✅ **赞成 74.94%，宪法委员会 7/7，epoch 637 已拨款** |

**86.72% 是投票期内的中途快照。** 大量投票在后期涌入并翻转了结果。

**这个错误的传播范围**：它支撑了一条五星级空头论点（"治理已切断核心研发资金"）、整个悲观情景的首要触发条件、以及 47% 的悲观概率。修正后：该论点删除，悲观概率降至 42%，乐观概率升至 12%，第 5 章整章重写。

### 最该记住的一点

**风险被准确识别了，却没有当场消除。**

本报告初稿在附录 11.4 里**自己**把这条数字标注为"⚠️ 仅搜索摘要，未打开一手投票记录"；
在本记分卡的方法论弱点里**自己**写了"这是本期最重要却核实等级最低的数字，**下期必须补一手核实**"。

**然后就把它写进了核心结论。**

> **识别风险 ≠ 处理风险。** 把已知的高风险项推迟到"下期核实"，等于用一个正确的自我认知，
> 为一个错误的结论背书。**流程已据此修改：凡链上可查的事实，写作阶段就必须查链上。**

### 由此得出的一条硬规则（已建议写入 SKILL.md）

**多家媒体报道一致 ≠ 事实。** 它们很可能引用同一个时点的同一份快照。

本期用一手 API 推翻了**五处**广泛流传的说法：治理投票结果、TVL 历史高点、质押率、国库规模、基金会 BTC 持仓。
**五处没有一处是靠"多找几篇报道"能发现的。**

> **凡有公开 API 的指标，一律不用搜索摘要。** 这不是谨慎问题，是五次实测的结果。
> 对治理类数据尤其如此：**必须查最终状态（`ratified_epoch` / `enacted_epoch`），不得使用任何时点的得票率报道。**
